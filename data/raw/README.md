# data/raw

Put downloads and exports here. Everything in this folder except this file and `.gitkeep` is ignored by git, so it never gets committed or published.

Write down where each file came from in your project README: the source, the date you got it, and any terms of use.

Never put anything here that you would not want on the open internet *if you later move it into `data/processed/`*. Check processed files for personal data before you commit them.
